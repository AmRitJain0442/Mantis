# Mantis brand assets

- `mantis-mark.png` — transparent standalone mark for the product header and favicon.
- `mantis-wordmark.png` — transparent graphite horizontal lockup for light surfaces.
- `mantis-wordmark-dark.png` — light horizontal lockup on a graphite panel for dark surfaces.

The four signal colors follow the product's causal path: agent intent, tool call,
application boundary, and user impact.
